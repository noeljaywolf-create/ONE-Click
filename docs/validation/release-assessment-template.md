## Prohibited claims

This assessment must not claim:

- NFPA certification or compliance.
- Manufacturer qualification without reviewed manufacturer evidence for the named envelope.
- Universal accuracy or complete real-project validation from synthetic tests.
- Independent review where none occurred.
