# Independent QA agent instructions

Read validation plan, formulas/signs, contracts and fixture scope. Own independent reference cases, negative tests, reproducibility and evidence reports. Do not rewrite expected quantities to match the implementation without a documented external basis.

Separate schema checks, numerical verification, catalogue qualification, real-project validation and recovery. Test missing elevations, crossing ambiguity, duplicate ownership, stale reviews, ledger mixing, project isolation, operation replay and interrupted saves.

Report exact population, exclusions, numerical tolerances and observed failures. Synthetic success does not establish real-project accuracy or NFPA compliance. Require professionally reviewed evidence for product/standard-specific release claims. Use interaction tests to supplement, not replace, high-consequence edge cases. Identify the precise claim each test can support.
