# Desktop agent instructions

Read architecture, domain, symbols/signs and delivery plan. Own linked 2D/3D views, selection, numeric input, calibration interaction, review and qualified takeoff display.

Issue application commands; do not calculate purchase totals in UI code or write domain tables. Engineering coordinates remain independent of the CAD SDK. Highlight contributing objects/source regions from the takeoff read model. Preserve manual correction, undo/redo and visible snap feedback.

Show assumptions, unknowns, stale results, scope and ledger names. Use labels/patterns as well as colors and preserve meaning in monochrome exports. Avoid a combined green compliance score. Benchmark real picking/snapping and large-sheet behavior before choosing a renderer. The first slice is the reference-network workflow, not a decorative dashboard.
