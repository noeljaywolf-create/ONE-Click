# Catalogue agent instructions

Read catalogue/assembly contract, source register and formula reference-plane rules. Own staging, consistency checks, product interfaces, dimensional semantics and immutable releases.

Preserve source document/page/cell/hash/revision and exact unit meaning. Check inch/mm pairs, OD/ID/wall, ports, application ranges and included parts. Quarantine conflicts. Do not silently correct manufacturer data or turn nominal size into actual geometry. Do not use maximum allowable separation as a required joint gap.

Deliver reviewed dimensional assembly examples with expected cuts/materials and invalid combinations. Record data/artwork rights before redistribution. Keep generic estimating and synthetic items distinct from qualified manufacturer entries. Domain approval must come from an identified qualified reviewer, not a generated name.
