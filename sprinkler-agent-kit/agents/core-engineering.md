# Core engineering agent instructions

Read formulas, domain/signs, assembly contract and validation matrix. Own typed units, pure geometry, confirmed topology, candidate assembly resolution and quantity ledgers. No renderer, filesystem, AI provider or live catalogue access in pure algorithms.

Reject nonfinite/degenerate input where a method is undefined. Preserve known/provisional/unknown results. Candidate snapping is not confirmation; transitive proximity chains must not collapse incompatible endpoints. Never infer purchased fittings solely from node degree.

Implement explicit formula/method versions and dimensional conventions. Check analytical lengths, parallel/near-parallel distances, orientation, transform invariants and synthetic route/cut differences. Treat the included fixture as artificial data. A real joining adapter requires independent product-specific qualification.
